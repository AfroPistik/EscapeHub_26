2. Checklist ανά Sprint για τον Scrum Master
Ο Scrum Master χρησιμοποιεί το ακόλουθο checklist σε κάθε Sprint για να διασφαλίσει την τήρηση της διαδικασίας:

Έναρξη Sprint (Sprint Planning)
[ ] Έχει γίνει η επιλογή των User Stories από το ιεραρχημένο Product Backlog για το τρέχον Sprint.

[ ] Οι εκτιμήσεις (Story Points) έχουν συμφωνηθεί από κοινού από την ομάδα ανάπτυξης.

[ ] Τα tasks έχουν ανατεθεί ισότιμα στα 9 μέλη, διασφαλίζοντας ότι όλοι έχουν σαφή ρόλο και ευθύνη για stories.

Κατά τη διάρκεια του Sprint (Execution & Monitoring)
[ ] Ελέγχεται καθημερινά η πρόοδος στα branches και διασφαλίζεται η εφαρμογή των κανόνων Branch Protection.

[ ] Ελέγχεται ότι τα Pull Requests συνοδεύονται από τα απαραίτητα automated tests και περνούν το CI.

[ ] Παρακολουθείται η τήρηση του κανόνα των code reviews (τουλάχιστον 2 ανά άτομο).

[ ] Ελέγχεται ότι τα μέλη ενημερώνουν τακτικά το AI-usage log (συμπεριλαμβανομένης της υποχρεωτικής καταγραφής λανθασμένης πρότασης AI).


Λήξη Sprint (Review & Retrospective)
[ ] Επαλήθευση ότι τα ολοκληρωμένα stories πληρούν πλήρως τον ορισμό του Definition of Done (DoD).

[ ] Προετοιμασία των απαντήσεων για τις ερωτήσεις αυτοελέγχου της ομάδας (σχετικά με stories, εκτιμήσεις, tests, commits, versions).

[ ] Καταγραφή τυχόν αποκλίσεων μεταξύ εκτιμήσεων και πραγματικής προόδου για τη βελτίωση των μελλοντικών Sprint Plannings.

3. Ερωτήσεις Αυτοελέγχου της Ομάδας (Βασισμένες στην §8)
Η ομάδα θα πρέπει να μπορεί να απαντά τεκμηριωμένα σε αυτά τα ερωτήματα σε κάθε αξιολόγηση:

Σχεδιασμός & Πρόοδος: Ποια user stories σχεδιάστηκαν και πόσα ολοκληρώθηκαν σε κάθε sprint; Πώς συγκρίνονται οι αρχικές εκτιμήσεις με την πραγματική πρόοδος;

Απόδειξη Ολοκλήρωσης (DoD): Πώς αποδεικνύεται ότι ολοκληρώθηκε ένα συγκεκριμένο story; Ποια συγκεκριμένα tests το καλύπτουν και διασφαλίζουν την ορθότητά του;

Ιχνηλασιμότητα: Σε ποιο issue, pull request, commit και release αντιστοιχεί η εκάστοτε λειτουργία του συστήματος;

Έκδοση & Διαφορές: Ποια ακριβώς έκδοση εκτελείται αυτή τη στιγμή στο περιβάλλον/CI και σε τι διαφέρει από την προηγούμενη έκδοση;

5. Ερωτήματα προς τον Διδάσκοντα
