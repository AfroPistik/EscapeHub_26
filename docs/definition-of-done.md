# Definition of Done

Ένα story θεωρείται ολοκληρωμένο μόνο αν ισχύουν όλα:

- [ ] Τα acceptance criteria καλύπτονται από αυτοματοποιημένους ελέγχους που περνούν
- [ ] Ο κώδικας έχει ενσωματωθεί στο `main` μέσω pull request
- [ ] Το PR έχει εγκριθεί από τουλάχιστον ένα άλλο μέλος της ομάδας
- [ ] Το CI είναι επιτυχές (build, tests, στατική ανάλυση)
- [ ] Η τεκμηρίωση (README, OpenAPI, CHANGELOG) έχει ενημερωθεί όπου χρειάζεται
- [ ] Το PR συνδέεται με issue και το πεδίο χρήσης AI είναι συμπληρωμένο
- [ ] Δεν υπάρχουν κωδικοί, κλειδιά ή προσωπικά δεδομένα στο αποθετήριο

## Κλίμακα εκτίμησης
Fibonacci: 1, 2, 3, 5, 8, 13. Το 13 σημαίνει ότι το story πρέπει να σπάσει.
